# Campaign index

One row per profiling campaign. Cells are short on purpose — the campaign page carries the
detail and the ledger carries the full record. Status vocabulary: `open` / `complete` /
`parked` / `no-go` / `draft` (see [README](README.md)). Release states were verified against
library git tags on 2026-09-27; "unreleased" means merged to `main` but in no tag yet.

Mind paths are relative to the PyAutoMind repo. Full pages exist for the four live campaigns;
every other page is a header-only stub awaiting backfill (phase 2 of epic
`profiling-research-wiki`).
